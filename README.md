# MiniStore

A simple static mini fashion store demo built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main page layout
- `style.css` — page styling
- `script.js` — product rendering and cart functionality

## How to use

1. Open `index.html` in a browser.
2. Add products to the cart.
3. Use the cart sidebar to update quantities or checkout.

## Notes

- No build step is required.
- This is a frontend-only demo.
